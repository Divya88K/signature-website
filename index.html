🔏 SignVerify

Digital Signature Verification System

A defence equipment supplier exchanges contracts electronically. A digital signature proves a document is authentic and has not been modified since it was signed.

Workflow

  1. Generate keys – RSA-2048 key pair, created inside your browser.
  2. Sign – the document is hashed with SHA-256 and signed with RSA-PSS.
  3. Download the small .sig file.
  4. Verify – document + signature + public key → VALID or INVALID.

Security notes

  • RSA-PSS with SHA-256 (not textbook RSA), using the browser's Web Crypto API.
  • The private key is non-extractable: it cannot be read, shown or downloaded, even by this page's own code, and nothing is ever uploaded to a server.
  • Files are checked for type, size, emptiness and file signature before use.

Generate keys

Creates an RSA-2048 key pair for this browser session. The private key stays in memory and is lost when you close or refresh the page, so sign before you leave. Save the public key to verify later.
